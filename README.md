# 🌆 Smart City AI Platform

An AI-powered Smart City Platform built using Machine Learning, Deep Learning, NLP, Computer Vision, RAG and AI Agents.

## 🚀 Features

- Traffic Prediction
- Power Consumption Prediction
- Pollution Prediction
- Waste Classification
- Emergency Detection
- Citizen Complaint Analysis
- Government Document RAG
- AI Agents

## 🛠 Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- Scikit-Learn
- TensorFlow
- LangChain
- FAISS
- Groq

### Frontend
- Streamlit
- Plotly
